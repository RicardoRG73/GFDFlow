### Detailed Breakdown

- **`02-DOCS/wiki/`**: Documentation and User Manuals.
  - `theory.md`: Mathematical foundations, Taylor series approximations, least-squares weights, and interface formulations.
  - `api_reference.md`: Detailed technical documentation for all classes, functions, and modules.
  - `user_manual.md`: Narrative guide with step-by-step workflows, multi-layer interfaces, and practical examples.

- **`src/GFDFlow/`**: The core package containing the library logic.
  - `GFDM.py`: Main implementation of the `GFDMI_2D_problem` class.
  - `utils.py`: Utility functions for support node selection and normal vector calculations.
  - `visualization.py`: Comprehensive 2D and 3D visualization routines for solutions, meshes, and normal vectors.
  - `__init__.py`: Package initialization.

- **`examples/`**: Ready-to-run demonstration scripts.
  - `basic_example.py`: A complete example solving a 2D Laplacian problem.
  - **`legacy/`**: Adapted examples from the original project (`ex0` to `ex11`).
    - `Meshes/`: Contains JSON files for the geometries.
    - `figures/`: Resulting plots generated by the scripts.

- **`tests/`**: Unit tests to ensure core functionality.
  - `test_gfdmi.py`: Tests for initialization, support nodes, and assembly.

- **Other Files**:
  - `verify_refactor.py`: A quick-start script to verify the installation and refactoring.
  - `requirements.txt`: List of required Python packages (`numpy`, `scipy`, `matplotlib`, `calfem-python`).
  - `pyproject.toml`: Configuration for modern Python build tools and installation.

## Usage

```python
import numpy as np
import scipy.sparse.linalg as spla
from GFDFlow.GFDM import GFDMI_2D_problem

# 1. Provide coordinates, triangles, and normal vectors
# 2. Define the differential operator coefficients (L) and source function
# 3. Create the problem instance:
problem = GFDMI_2D_problem(coords, triangles, normal_vectors, L, source)

# 4. Set materials and boundary conditions
# 5. Assemble and solve
K, F = problem.discretization_K_F(continuous=True)
U = spla.spsolve(K, F)
```
