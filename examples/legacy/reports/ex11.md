## 1. Executive Summary

- **Objective:** Model geotechnical steady-state seepage flow through an engineered tailings dam embankment, impounded tailings reservoir, and underlying bedrock foundation.
- **Domain Type:** Multi-region irregular cross-section representing a tailings storage facility (dam embankment, tailings beach/pond, and foundation rock).
- **Governing Physics:** 2D Laplace groundwater flow ($\nabla^2 u = 0$) across contrasting hydraulic conductivities spanning four orders of magnitude ($k_{\text{tailing}} = 1.0$, $k_{\text{dam}} = 10^{-2}$, $k_{\text{rock}} = 10^{-4}$).
- **Key Validation Points:** Flow redistribution across multi-material geological/engineered strata, phreatic seepage dissipation, and continuous interface flux conservation.
- **Associated Code:** [`../ex11.py`](../ex11.py)
- **Mesh / Input Data:** [`../meshes/mesh11.json`](../meshes/mesh11.json)

## 2. Problem Formulation & Boundary Conditions

### 2.1 Governing Differential Operator
Under the general operator formulation $L u = f$ (see [Theory §2](../../../02-DOCS/wiki/theory.md#2-the-general-second-order-linear-differential-operator)):

$$L u = \nabla^2 u = u_{xx} + u_{yy} = 0$$

- **Operator Vector:** $\mathbf{L} = [0, 0, 0, 1, 0, 1]^T$
- **Conductivity Properties:**
  - Impounded Tailings: $k_{\text{tailing}} = 1.0$
  - Dam Embankment: $k_{\text{dam}} = 10^{-2} = 0.01$
  - Foundation Rock: $k_{\text{rock}} = 10^{-4} = 0.0001$
- **Source Term:** $f(x, y) = 0$

### 2.2 Boundary & Interface Conditions
Boundaries and internal strata interfaces (see [Theory §6](../../../02-DOCS/wiki/theory.md#6-implementation-of-boundary-conditions) and [Theory §7](../../../02-DOCS/wiki/theory.md#7-interface-flux-balance-for-layered-media)):

| Identifier | Type | Condition | Description |
|---|---|---|---|
| `left` | Dirichlet | $u = 300.0$ | Upstream tailings pond hydraulic head |
| `right` | Dirichlet | $u = 200.0$ | Downstream toe drainage hydraulic head |
| `bottom` | Neumann | $\frac{\partial u}{\partial n} = 0$ | Impermeable deep bedrock boundary |
| `interface_a`, `interface_b`, `interface_c` | Interface | Continuous flux $\beta = 0$ | Material interfaces between tailings, dam, and foundation rock |

## 3. Geometry and Spatial Discretization

### 3.1 Domain Layout
The computational mesh represents a typical tailings facility profile:

## 4. GFDFlow Pipeline & Implementation

The implementation in [`../ex11.py`](../ex11.py) configures the multi-material geotechnical assembly:

```python
from GFDFlow.GFDM import GFDMI_2D_problem as gfdm
import scipy.sparse as sp

problem = gfdm(coords, triangles, normal_vecs, L, source, M_pinv=M_pinv, support_stencils=support_stencils)

problem.material("tailing", ktailing, tailing_nodes)
problem.material("dam", kdam, dam_nodes)
problem.material("rock", krock, rock_nodes)

problem.dirichlet_boundary("left", left_nodes, left_dirichlet)
problem.dirichlet_boundary("right", right_nodes, right_dirichlet)
problem.neumann_boundary("bottom", krock, bottom_nodes, neumann_0)

problem.interface("interface_a", ktailing, kdam, interface_a_nodes, None, beta, None, tailing_nodes, dam_nodes)
problem.interface("interface_b", ktailing, krock, interface_b_nodes, None, beta, None, tailing_nodes, rock_nodes)
problem.interface("interface_c", kdam, krock, interface_c_nodes, None, beta, None, dam_nodes, rock_nodes)

K, F = problem.continuous_discretization()
U = sp.linalg.spsolve(K, F)
```

## 5. Numerical Results and Discussion

### 5.1 Hydraulic Head Field (2D Contour)
The contour plot displays the resulting flownet and head dissipation throughout the dam profile:

![Tailings Dam Seepage Contour Map](../figures/ex11/contourf.png)

**Key Observations:**
- **Head Dissipation Across the Dam:** The compacted dam body ($k_{\text{dam}} = 0.01$) acts as an effective hydraulic barrier, containing most of the $100\,\text{m}$ total head drop across its cross-section.
- **Foundation Flow Protection:** The low-permeability foundation bedrock ($k_{\text{rock}} = 0.0001$) prevents deep seepage losses beneath the impoundment.
- **Interface Stability:** High conductivity contrast across three converging materials is resolved cleanly without spurious numerical oscillations.
