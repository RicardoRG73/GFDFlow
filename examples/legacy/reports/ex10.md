## 1. Executive Summary

- **Objective:** Solve both stationary and time-dependent diffusion across a domain with an embedded circular inclusion ($r = 0.25$) using explicit Forward Euler and implicit Crank-Nicolson time integration schemes.
- **Domain Type:** Square $[-1, 1] \times [-1, 1]$ containing a centered circular inclusion of radius $R = 0.25$.
- **Governing Physics:**
  - *Stationary:* $\nabla^2 u = 0$ with permeability contrast $k_0 = 100$ (outer matrix) and $k_1 = 1$ (inner circle).
  - *Transient:* $\frac{\partial u}{\partial t} = \nabla^2 u$ integrated over $t \in [0, 0.1]$.
- **Key Validation Points:** Time-stepping stability comparisons between explicit Forward Euler and implicit Crank-Nicolson methods applied to spatial GFDM matrices.
- **Associated Code:** [`../ex10.py`](../ex10.py)
- **Mesh / Input Data:** [`../meshes/mesh10.json`](../meshes/mesh10.json)

## 2. Problem Formulation & Boundary Conditions

### 2.1 Governing Equations
- **Stationary Operator:** $L u = u_{xx} + u_{yy} = 0$ with $\mathbf{L} = [0, 0, 0, 1, 0, 1]^T$.
- **Conductivities:**
  - Outer matrix ($r > 0.25$): $k_0 = 100.0$
  - Inner inclusion ($r < 0.25$): $k_1 = 1.0$

### 2.2 Boundary & Interface Conditions
- **Outer Boundaries:** Non-homogeneous Dirichlet conditions:
  - Bottom ($y = -1$): $u = 0$
  - Right ($x = 1$): $u = \sin(\pi(y + 1)/4)$
  - Top ($y = 1$): $u = \sin(\pi(x + 1)/4)$
  - Left ($x = -1$): $u = 0$
- **Circular Interface:** Continuous potential and normal flux conservation ($\beta = 0$).

## 4. GFDFlow Pipeline & Implementation

The implementation in [`../ex10.py`](../ex10.py) compares stationary and time-stepping solvers:

```python
from GFDFlow.GFDM import GFDMI_2D_problem as gfdmi
import scipy.sparse as sp

problem = gfdmi(coords, faces, normal_vecs, L, source, M_pinv=M_pinv, support_stencils=support_stencils)
# ... [assign materials, boundaries, and interface]

K, F = problem.continuous_discretization()

# 1. Stationary solution
U_steady = sp.linalg.spsolve(K, F)

# 2. Crank-Nicolson implicit time-stepping: (I - dt/2 K) U^{n+1} = (I + dt/2 K) U^n + dt F
A = sp.eye(len(F)) - dt/2 * sp.diags(beta) @ K
B = sp.eye(len(F)) + dt/2 * sp.diags(beta) @ K
for i in range(m - 1):
    U[i + 1] = sp.linalg.spsolve(A, B @ U[i] + dt * F)
```

**Key Observations:**
- **Inclusion Shielding:** Flow is strongly channeled through the high-permeability matrix ($k_0 = 100$), bypassing the core inclusion ($k_1 = 1$).
- **Scheme Comparison:** Crank-Nicolson provides unconditional stability for time step $\Delta t = 0.0001$, avoiding the Courant time-step limitations of explicit Euler.
